# Survey protocol

1. Search primary papers, official proceedings, and official code repositories.
2. Record exact arXiv, OpenReview, DOI, repository commit, and paper-version identifiers in `papers.yaml`.
3. For every candidate claim, complete every column of `claim-matrix.csv`.
4. Perform an independent adversarial novelty review before treating novelty as verified.
5. Keep source facts, inferences, hypotheses, and experimental results explicitly labeled.

No quantization method is implemented by this scaffold.
